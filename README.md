# OURA TRENDS AND CORRELATIONS ANALYZER
#### Video Demo:  https://youtu.be/_CJZABVvYGI
#### Description: This is my Oura Ring CSV data analyzer which takes in an Oura ring's csv through commandline, using argparse, with the following options **enabled** from Oura's website: _"Sleep Score", "Readiness Score", "Activity Score", "Average HRV", "Lowest Resting Heart Rate", "Average Resting Heart Rate", "Respiratory Rate","Total Sleep Duration", "Deep Sleep Duration", "REM Sleep Duration", "Sleep Efficiency", "Steps."_ It uses a DictReader and several custom functions to parse through the CSV file, read the data, and then calculate a group of "General Summary" metrics such as average scores for various metrics and finding the best scores and their associated dates. The code accounts for general mistakes in commandline such as FileNotFoundErrors. It also accounts for missing data points within the CSV and None values (e.g. if someone missed a night of sleep for whatever reason), ensuring the program runs without crashing. The more interesting part of the project is the correlation aspect, which uses the equation for a Pearson Coefficient Correlation to find the direction and magnitude of correlation between two variables. The equation is in the code! It ranges from -1 to 1, with proximity to 1 or -1 indicating strength of correlation and sign indicating positive correlation (+) or inverse correlation (-). The program asks for input from the user for a name of a metric they are interested in, accounting for typos and other user errors in the terminal. Then, provided a valid input is entered, the program calculates the correlation coefficient for each metric compared to the target metric. It then uses matplotlib to generate a bar chart png that is ranked in magnitude order and color coded to indicate positive or negative correlation that displays the Pearson Coefficient Correlation for each metric, providing an interesting way to visualize various correlations between metrics that is not provided by Oura. I've included my own sample Oura CSV for you to use in case you don't have an Oura ring: here's the terminal line as well so you don't have to type it out: **python project.py oura_2026-06-07_2026-07-05_trends.csv**. I hope you like it! The program uses matplotlib which must be installed.
